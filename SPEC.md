## 2. TypeScript Data Contracts (`src/types/index.ts`)
```typescript
export type SpeakerRole = 'client' | 'caller';

export type CallStage =
  | 'opener'
  | 'discovery'
  | 'pitch'
  | 'objection_handling'
  | 'closing';

export interface TranscriptTurn {
  id: string;
  speaker: SpeakerRole;
  text: string;
  timestamp: number;
}

export interface ObjectionRule {
  trigger: string;      // e.g., "Not interested / busy"
  strategy: string;     // e.g., "Acknowledge, ask for 25 seconds, pivot to core pain"
}

export interface SalesSkill {
  id: string;
  name: string;
  agencyOffer: string;  // What we sell
  targetAudience: string;
  callGoal: string;     // e.g., "Book a 15-minute discovery Zoom call"
  toneRules: string[];
  fillerBridges: string[]; // Instant natural phrases caller can say while AI loads
  objectionMatrix: ObjectionRule[];
}

export interface SuggestRequestPayload {
  turns: TranscriptTurn[]; // Max last 6 turns
  skill: SalesSkill;
  currentStage: CallStage;
}
```

## 3. Speech-to-Text Adapter Spec (`src/lib/stt-adapter.ts`)
Must export a clean class or factory `createSTTAdapter(callbacks)`:
- **Callbacks:**
  - `onInterim(text: string): void` — Fires immediately as words are spoken.
  - `onFinal(text: string): void` — Fires when a sentence/phrase finishes.
  - `onError(err: string): void`
  - `onStatusChange(isListening: boolean): void`
- **Resilience Rule (Critical for Chrome):**
  - Set `recognition.continuous = true` and `recognition.interimResults = true`.
  - Set `recognition.lang = 'en-US'`.
  - Maintain an internal `shouldBeListening` boolean. If Chrome fires `onend` while `shouldBeListening === true`, automatically restart `recognition.start()` within 150ms so the mic never silently drops during a call.

## 4. AI Sales Brain & Prompt Rules (`src/lib/skills.ts` & `/api/suggest/route.ts`)
### Spoken-English System Prompt Rules:
The system prompt generated by `buildSystemPrompt(skill, currentStage)` MUST enforce:
1. **Strict Length Limit:** Maximum **2 sentences** and **under 35 words total**. Cold callers cannot read paragraphs aloud without sounding robotic.
2. **Spoken Rhythm:** Use natural contractions (*"we're"*, *"that's"*, *"I'll"*) and conversational pauses (`...`).
3. **Vocal Emphasis:** Wrap the **2 to 4 most important punchwords** in `**bold**` so the caller knows where to inflect their voice.
4. **Always End With a Low-Friction Question:** Keep control of the dialogue (e.g., *"Fair enough?"*, *"Sound mildly interesting, or totally off base?"*).
5. **Output Format:** Output ONLY the exact spoken words the caller should read next. Zero preamble, zero quotation marks, zero stage directions.

### API Endpoint Security & Validation (`src/app/api/suggest/route.ts`):
- Validate that `turns` is an array (slice to last 6 turns maximum; truncate any single turn text at 500 chars).
- Support `GROQ_API_KEY` (using model `llama-3.3-70b-versatile`, `temperature: 0.4`, `max_tokens: 90`, `stream: true`).
- Return a standard `ReadableStream` of plain text UTF-8 chunks so the frontend can render words within 300-500ms.

## 5. Split-Screen UI Specification (`src/app/page.tsx`)
- **Top Bar:**
  - App Title + Live Status Badge (`Listening` / `Paused`).
  - **Start / Stop Listening Button** (Green/Red).
  - **Active Speaker Toggle:** `Input Role: Prospect (Default)` vs `Input Role: Caller (Me)` + a manual text input box to type a simulated client objection if testing without a mic.
  - **Call Stage Selector Pills:** `Opener` | `Discovery` | `Pitch` | `Objection` | `Close`.
  - **Customize Skill Button:** Opens `SkillModal`.
- **Left Panel (40% width) — `TranscriptPanel.tsx`:**
  - Auto-scrolling chat history showing `[Prospect]` and `[You]` bubbles.
  - Live pulsing box at the bottom displaying `interimText` in real time as speech is detected.
- **Right Panel (60% width) — `TeleprompterCard.tsx`:**
  - **Top Strip (Instant Filler Bridges):** Always-visible badges from `skill.fillerBridges` (e.g., *"Totally hear you on that..."*, *"Good question, honestly..."*) that the caller can read in 0ms while the AI streams.
  - **Main Teleprompter Box:** Huge font (`text-2xl md:text-3xl leading-relaxed`), high-contrast background, rendering `**bold**` punchwords in bright yellow/emerald so the caller's eyes lock onto vocal emphasis.
  - **Quick Objection Trigger Buttons:** 4 one-click buttons (*"Busy right now"*, *"Send an email"*, *"Already have an agency"*, *"How much is it?"*) that immediately trigger an AI counter-response even if STT missed a word.
